# 墨集 0.1.0 用户指南（候选版）

## 当前可用流程

1. 选择一个授权目录或单个文件。
2. 启动扫描并等待任务完成；扫描只登记元数据，不移动或删除原文件。
3. 使用搜索、格式、状态、来源、集合、标签和收藏筛选结果。
4. 通过结果中的稳定文档 ID 打开文档。Markdown/TXT/CSV 可编辑；PDF 和 Office 文件按当前能力显示只读或降级状态。
5. 添加批注或编辑文本。保存前会创建 Snapshot，并检查源文件 SHA-256 是否被外部修改。
6. 对图片和无文本层 PDF 启动本地 OCR。OCR 模型必须预先放在应用数据目录的 `ocr-models` 下，运行时不下载模型。
7. AI 功能只在 Rust 侧读取 Windows Credential Manager 中的凭据。`suggest` 只返回建议；写回必须通过用户确认、Snapshot 和冲突检查。
8. 外部修改或写回失败时，停止覆盖并从 Snapshot 列表选择恢复。

## 数据位置与恢复

应用数据位于 `%LOCALAPPDATA%\\com.moji.desktop`。数据库密钥保存在 DPAPI 保护的 `library.sqlite3.key` 侧车文件中。备份或恢复数据库前，先备份整个应用数据目录；不要把数据库复制到临时目录并尝试绕过密钥。

## 安装与升级

发布候选使用 NSIS `currentUser` 安装模式，预期不需要管理员权限。升级应使用同一产品标识 `com.moji.desktop`。卸载预期保留用户数据；确认数据备份后再由用户手动删除应用数据目录。当前安装器尚未生成，以上行为等待 Windows 10/11 实机验收。

## 隐私与离线行为

OCR 完全离线。文档正文通过统一页片段接口读取；路径、API Key 和未授权内容不会发送到前端。真实 AI 请求需要用户自己的 Credential Manager 凭据，并且本候选版尚未完成真实 API 冒烟。
