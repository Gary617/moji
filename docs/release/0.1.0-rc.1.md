# 墨集 0.1.0-rc.1 发布说明

## 发布结论

**不可发布。** 本候选版保留完整安全门禁，但当前工作站无法完成生产 SQLCipher/OpenSSL 构建，因此没有可安装包。

## 已验证

- `pnpm test`：PASS，7 个测试文件、17 个测试。
- `pnpm test:rust`：PASS，43 个测试，使用 `--no-default-features` 的开发 SQLite 路径。
- `pnpm build`：PASS，Vite 转换 1811 个模块。
- `cargo fmt --manifest-path src-tauri/Cargo.toml --all -- --check`：PASS。
- `git diff --check`：PASS。
- `pnpm test:editor-poc`：BLOCKED，24 个样本没有配置 Node runtime bridge；保留此失败结果，不以 mock 或浏览器 POC 替代。
- 浏览器 Office POC：24/24 PASS；这不是已安装 Tauri 宿主的写回证据。
- OCR 小样本：预热文本页 240-271 ms，空白页 225 ms，峰值 159.7 MiB。
- 索引小样本：1,000 条内存记录查询 p95 53 ms。

- `pnpm build:desktop`：FAIL，同一 vendored OpenSSL/Perl 阻断；没有 NSIS 或校验值可发布。`src-tauri/target/release/moji-desktop.exe` 是早于本候选的旧输出，未通过当前 secure-db/安装器验证，不能分发。

- 真实 WebView2 安全策略、键盘/DPI/视口矩阵、崩溃断电恢复和大文件后台负载：NOT TESTED。
- 真实 OpenAI Credential Manager/SSE 流程：NOT TESTED。

## 接续条件

在具备 Rust/MSVC、Perl、NSIS 和可复现 Windows 10/11 测试环境的构建机上：

1. 运行 `pnpm install --frozen-lockfile`、`pnpm test`、`pnpm test:rust`、`pnpm build` 和 `pnpm build:desktop`。
2. 启动构建产物，确认 `PRAGMA cipher_version` 非空并完成加密数据库烟测。
3. 对 NSIS 安装包计算 SHA-256，完成首次启动、升级、卸载和恢复演练。
4. 重新填写 `docs/release/TEST_REPORT-0.1.0-rc.1.md`，只有所有高风险门关闭后才可改为“可以发布”。

第三方许可证和模型校验值见 [`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md) 与 [`docs/ocr-models.md`](../ocr-models.md)。
